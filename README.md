# MotoGestão

Demonstração acadêmica de um portal para uma loja de motos e peças.

Vue 3 e Tailwind via CDN. Dashboard, clientes, peças e vendas com dados fictícios e armazenamento no navegador de cada visitante. Sem backend e sem cache offline.

## Publicação no GitHub Pages

1. Envie estes arquivos para um repositório público da sua conta pessoal.
2. Em Settings > Pages, selecione Deploy from a branch.
3. Selecione a branch main e a pasta / (root), e salve.
4. Aguarde o GitHub informar o endereço publicado.

Abra o endereço publicado para verificar o dashboard. O exemplo do guia está em pratica.html.
